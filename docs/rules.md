# Rule reference

120 rules. Generated by `mechcheck rules --markdown` — do not edit by hand.

Every rule can be switched off for one line with a source comment:

```latex
\includegraphics{decorative-divider}  % mechcheck: off FIG002 -- decorative, no content to describe
```

## accessibility

| id | severity | what it checks | why | how to fix |
|---|---|---|---|---|
| `ACC001` | error | Figure without a \Description | ACM requires alt text for every figure and validates it in TAPS; at ASSETS an inaccessible submission is desk-rejected. | Add \Description{...} inside the figure: say what the figure shows and what the reader should conclude from it. |
| `ACC002` | error | \Description is a placeholder | 'A figure.' satisfies the syntax and helps nobody; it is worse than nothing because it silences the check. | Describe the content: axes, trend, and the point the figure makes. |
| `ACC003` | warn | \Description repeats the caption | A screen-reader user hears the caption already; repeating it verbatim adds nothing they did not have. | Describe what is visually in the figure, which the caption does not say. |
| `ACC004` | warn | Meaning carried by colour alone | 'the red line' is unreadable to a colour-blind reader and to anyone printing in greyscale -- about 8% of male readers. | Add a second cue: 'the red dashed line (baseline)'. |
| `ACC005` | info | Complex table without a description | ACM suggests describing the structure of complex tables so a screen reader can convey the layout. | Add \Description{...} summarising what the table contains. |
| `ACC006` | warn (needs build) | PDF is not tagged | An untagged PDF has no reading order, so assistive technology cannot navigate it. ASSETS requires an accessible PDF at submission. | Compile with a recent acmart (which sets pdfmanagement/tagging), or run the publisher's accessibility pipeline. |
| `ACC007` | info | Figure text likely too small | A figure scaled below about half its natural width usually carries axis labels too small to read in print. | Redraw the figure at the size it will be printed rather than scaling it down. |

## anonymity

| id | severity | what it checks | why | how to fix |
|---|---|---|---|---|
| `ANON001` | error | Author identity present in an anonymous submission | Author names in a double-anonymous submission are the single most common desk reject. | Add the `anonymous` class option -- acmart then replaces the author block automatically. |
| `ANON002` | error | Acknowledgements left in an anonymous submission | Acknowledgements name colleagues, funders and institutions -- they identify the authors as reliably as the author block. | Put them in acmart's acks environment, which the anonymous option removes for you; otherwise guard the section so it only appears in the camera-ready version. |
| `ANON003` | error | Identifying link | A repository or project URL under your own account de-anonymises the submission in one click. | Use an anonymised mirror (anonymous.4open.science, an anonymous OSF view-only link) for review. |
| `ANON004` | warn | Funding statement in an anonymous submission | A named grant identifies the group as precisely as a name does. | Move the funding statement to the camera-ready version. |
| `ANON005` | warn | Self-citation phrased in the first person | 'In our previous work [12]' tells the reviewer exactly who wrote this. Venues ask you to cite your own work in the third person instead. | Rewrite as 'Prior work [12] showed ...'. Note that ASSETS explicitly asks you NOT to anonymise the citation itself. |
| `ANON006` | error (needs build) | PDF metadata names the author | Reviewers see the document properties. An anonymised body with your name in the PDF metadata is the classic near-miss. | Clear the metadata: \hypersetup{pdfauthor={}} , or let the anonymous class option do it. |
| `ANON007` | error | Anonymous option left in a camera-ready document | The mirror image of ANON001, and just as costly: the published version credits 'Anonymous Author(s)'. | Remove `anonymous` (and `review`) from \documentclass for the final version. |

## bib

| id | severity | what it checks | why | how to fix |
|---|---|---|---|---|
| `BIB001` | warn | No bibliography file found | Without a .bib the citation checks cannot run at all, so a missing file silently disables half the tool. | Add \bibliography{refs} (BibTeX) or \addbibresource{refs.bib} (biblatex). |
| `BIB002` | warn | Entry missing a required field | A reference without a venue or a year cannot be looked up, and the reference list prints a visible gap. | Fill the field in from the publisher's page, not from memory. |
| `BIB003` | warn | Duplicate bibliography entry | The same work under two keys cites inconsistently and inflates the reference count. | Keep one entry and update the citations that used the other key. |
| `BIB004` | info | Preprint cited where a published version may exist | Citing the arXiv version of a paper that appeared at CHI three years ago reads as not having followed the literature. | Check for the published version and cite that; keep the preprint only if there is none. |
| `BIB005` | info | Unprotected proper noun in a title | BibTeX lower-cases titles for most styles, so 'German' silently prints as 'german'. | Brace the word: {German}. |
| `BIB006` | error | 'et al.' inside an author field | BibTeX reads 'et al.' as a person's name and prints it as an author; the abbreviation is the style's job, not yours. | List every author, separated by ' and '. Use 'and others' if you truly must truncate. |
| `BIB007` | error | Authors separated by commas instead of 'and' | BibTeX splits authors on ' and '; a comma-separated list collapses into one enormous surname. | Separate every author with ' and '. |
| `BIB008` | info | Page range with a single hyphen | Page ranges take an en dash; BibTeX writes it as --. | Write pages = {101--110}. |
| `BIB009` | info | Missing DOI | The ACM Reference Format expects a DOI; without one the reference cannot be resolved automatically and the online checks cannot verify it either. | Copy the DOI from the publisher's page into doi = {10.1145/...}. |
| `BIB010` | info | URL cited without an access date | A web source with no access date cannot be checked by a reader later, and most thesis regulations require one. | Add urldate = {2026-08-27} (biblatex) or note = {Accessed: 2026-08-27}. |
| `BIB011` | info | Inconsistent venue name for the same conference | 'Proc. of CHI', 'CHI '24' and the full ACM name in one bibliography print as three different venues. | Normalise the booktitle across entries -- bibtex-tidy or a shared string does this well. |
| `BIB012` | warn | Bibliography entry with a suspicious year | A year in the future or before 1900 is a typo, and typos in years are how a citation becomes unfindable. | Correct the year. |

|---|---|---|---|---|
| `BIO001` | error (network) | DOI does not resolve | A DOI that Crossref does not know is either mistyped or points at a work that does not exist. Both must be fixed before submission. | Open https://doi.org/<the DOI> yourself. If it 404s, find the real DOI on the publisher's page. |
| `BIO002` | error (network) | Cited title does not match the DOI | If the DOI resolves to a different paper, the citation sends the reader to the wrong work -- and every claim attributed to it is unsupported. | Replace either the DOI or the title so the entry describes one real work. |

## crossref

| id | severity | what it checks | why | how to fix |
|---|---|---|---|---|
| `REF001` | error | Reference to an undefined label | An undefined reference prints as '??' in the PDF -- the most visible possible sloppiness. | Fix the typo, or add the missing \label. |
| `REF002` | info | Label never referenced | A label nothing points at is dead weight -- and often the sign of a cross-reference that was meant to exist. | Reference it, or delete the label. |
| `REF003` | error | Duplicate label | LaTeX keeps only the last definition, so every reference silently points at the wrong place. | Rename one of them. |
| `REF004` | info | Missing non-breaking space before a cross-reference | 'Figure 7' must not break across a line; LaTeX only prevents that if you write the tie yourself. | Write Figure~\ref{...} with a tilde. |
| `REF005` | error | Citation key not in the bibliography | An unresolved citation prints as '[?]' and the entry is missing from the reference list. | Add the entry to the .bib file, or fix the key. |
| `REF006` | info | Bibliography entry never cited | Uncited entries bloat a .bib and hide the ones that matter; with biblatex they can also leak into the printed list. | Cite it or remove it -- keeping a personal 'to read' .bib separate works well. |
| `REF007` | info | Inconsistent cross-reference commands | Mixing \ref, \autoref and \Cref produces 'Figure 1', 'figure 1' and '1' in the same document. | Pick one (cleveref's \Cref is the usual choice) and use it everywhere. |
| `REF008` | warn | Prefixed cross-reference where \autoref would do | Writing the word yourself means two places to keep in step, and it is the half that goes wrong: a table renumbered into a figure still reads 'Table'. \autoref supplies the word from the label's own type. | Replace Figure~\ref{x} with \autoref{x}. |
| `REF009` | warn | Author name written out before \cite | 'Colley et al. [12]' spells out a name the bibliography style can produce itself, so the two drift apart when the entry changes; a textual citation command keeps them in one place. | Replace 'Name et al.~\cite{key}' with \citet{key} (natbib/acmart) or \textcite{key} (biblatex). |

|---|---|---|---|---|

## style

| id | severity | what it checks | why | how to fix |
|---|---|---|---|---|
| `STY001` | error | Unfinished-work marker left in the text | A TODO that reaches a supervisor or a reviewer costs more credibility than the missing content would have. | Resolve it, or move it to your issue tracker. |
| `STY002` | warn | Forced line break in running text | A \\ inside a paragraph breaks the line mid-sentence and leaves the previous line unjustified; it is almost always a leftover from editing. | Delete the \\ and let LaTeX break the paragraph, or start a new paragraph with a blank line. |

| `STY005` | warn | Space before punctuation | A space before a comma or full stop is a typing slip that survives into print. | Delete the space. |

| `STY007` | info | Hyphen used for a numeric range | A range takes an en dash (--) in LaTeX; a single hyphen prints too short. | Write 10--20. |
| `STY008` | warn | Mixed British and American spelling | Reviewers read inconsistent spelling as carelessness; it is also the commonest artefact of text assembled from several sources. | Pick one variety and apply it throughout. |
| `STY009` | info | Contraction in formal writing | Contractions are out of register for a thesis or an ACM paper. | Write the words out: don't -> do not. |
| `STY010` | info | Inconsistent Figure/Fig. abbreviation | 'Figure 1' in one paragraph and 'Fig. 1' in the next is the sort of inconsistency that makes a careful reader distrust the numbers too. | Use one form; ACM style spells out 'Figure'. |
| `STY011` | info | Sentence-ending period after an abbreviation | 'e.g. the' without a comma reads as a sentence break to LaTeX's spacing rules and prints a wide space. | Write 'e.g.,' and 'i.e.,' -- or use \eg macros. |
